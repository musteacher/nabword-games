Having trouble or have feedback? Here is how to find help and report a problem.

Quick troubleshooting

  • Close and reopen the game if the interface becomes unresponsive.
  • Check that the game is updated to the latest available version.
  • If a puzzle feels unsolvable, report its mode and level number so we can investigate.
  • For hints or progress issues, include what happened before the issue occurred.
  • For display issues, mention your device model and operating system.

Contact support

For bug reports, questions or feature feedback, contact our team. Please include the game name, your device model, iOS/Android version, app version and a short description of what happened. A screenshot is helpful when possible.
